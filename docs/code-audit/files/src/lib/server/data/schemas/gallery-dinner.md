## LA15-1 🟡 `year`는 연도가 아니라 자유 라벨이고, "모름"을 문자열로 담는다

6행 `year: z.string().min(1)`. 입력 스키마는 `trim().min(1).max(20)`이고 주석이 값의 정체를 밝힌다 —
"a year label ("2026", or "미상" from the migration)"(`domain/admin-records.ts:87-89`).

결과 둘:

1. **모름이 매직 문자열이다.** 소비자는 연도인지 추측해야 한다 — 공개 아카이브는 `/^\d{4}$/.test(g.year)`로
   거르고 아니면 날짜를 null로 둔다(`(public)/archive/+layout.server.ts:191`). 제목과 alt에는 그대로 `"미상"`이
   들어간다(`:187`, `:194`). 연도가 없다는 사실이 스키마에 없다(`nullable`이 아니다).
2. **저장 게이트가 입력보다 헐겁다.** 공백 라벨·20자 초과가 저장 게이트를 통과한다. `seminar.ts:21-22`가 스스로
   세운 원칙("저장 계층이 폼보다 헐거우면 … 퇴화한다")이 이 테이블에는 적용되지 않았다.

처방: 이름이 가리키는 대로라면 `year: z.string().regex(/^\d{4}$/).nullable()` + 표시 라벨은 화면이 만든다 —
**동작 변경**이며 `"미상"` 행의 데이터 마이그레이션이 필요하다. 최소 처방은 저장 스키마를 입력과 같은 길이 상한으로
맞추는 것(구조 변경에 가깝다).
