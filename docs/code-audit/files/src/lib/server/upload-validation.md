# `src/lib/server/upload-validation.ts` (61줄)

**접두사 `LB08-`** · 폼으로 받은 `File`을 형식(PDF/이미지)·크기로 검증하고 `AdminContentFile` 레코드를 만든다.

## LB08-1 🟡 호출부 0인 업로드 제약 사본이고, 값이 권위와 다르다 (`W-15`·`HS-13` 재확인)

운영 호출부가 **0**이다(`grep -rn "validateContentFile\|upload-validation" src` — 자기 테스트뿐). 업로드는 presign 경로로 옮겨 갔고
제약의 권위는 `services/uploads.ts:39-56`의 `PURPOSES`다. 두 표가 같은 것을 다르게 말한다.

|                | 이 파일 (3-6행)                 | `PURPOSES`                                                   |
| -------------- | ------------------------------- | ------------------------------------------------------------ |
| 이미지 최대    | `10 * 1024 * 1024` = 10,485,760 | `10_000_000` (`seminar-photo`·`study-photo`·`gallery-photo`) |
| PDF 최대       | `50 * 1024 * 1024` = 52,428,800 | `50_000_000` (`seminar-material`)                            |
| 포스터         | 없음                            | PNG/JPEG만, `15_000_000` (`seminar-poster`)                  |
| 형식 결정 단위 | `allowPdf` 불리언 하나          | purpose별 `types`                                            |

`upload-validation.test.ts`가 이 사본을 초록으로 유지한다 — 드리프트가 **테스트로 고정**돼 있다.
누가 "서버 쪽 업로드 검증"을 찾으면 이름상 이 파일을 먼저 보고 틀린 한도를 가져간다.
그리고 413을 내는 유일한 코드가 여기 있다(43행) — 살아 있는 presign 경로의 크기 초과는 400이다(`STATUS-CODES.md` HS-13, W-32 잔여).

`PRIORITY.md` W-15가 "통합이 아니라 **삭제** 대상"으로 판정했고 미처리다. 처방: 파일과 테스트 삭제(동작 변경 없음). 413이 필요하면 presign 크기 분기에 직접 둔다.

## LB08-2 🟡 내부도 계약이 흐리다 — 되살릴 경우를 위한 기록

삭제되지 않는다면 다음이 함께 고쳐져야 한다.

- **PDF 허용이 기본값이다**(24행 `options.allowPdf !== false`) — 옵션을 잊은 호출부가 PDF를 받는다. 허용 목록은 닫힌 쪽이 기본이어야 한다
- **한도 숫자가 두 번 적혀 있고 단위가 틀린다** — 5-6행 상수와 46-47행 문구 `"50MB"`·`"10MB"`가 따로다. 상수는 MiB(2^20)인데 문구는 MB라 쓴다
- **"검증"이 레코드를 발급한다**(50-59행) — `crypto.randomUUID()`로 id를 만들고 `url: null`인 `AdminContentFile`을 조립한다. 순수 검증과 식별자 발급이 한 함수에 있어, 검증만 필요한 호출자도 id를 받는다

## 확인했고 지적하지 않은 것

- **빈 파일과 `File`이 아닌 값을 같은 400으로**(16-22행) — 폼에서 파일 필드가 비면 빈 `File`이 온다. 둘을 나눌 이유가 없다
- **판별 유니온 반환**(8-10행) — `success` 판별자로 좁혀지고 `status`가 `400 | 413`으로 닫혀 있다. 형태는 좋다
- **이미지 형식 목록**(3행) — `services/uploads.ts:39`의 `IMG`와 같은 세 형식이다. 값이 같다는 것은 LB08-1의 중복을 줄이지 않지만 이 항목 자체는 드리프트가 아니다
