원고 위의 공개 영역

Extending the manuscript language to twenty-two pages leaving Notion

Draft 2026-08-23 · Not a Notion port

Abstract

노션에서 옮겨오는 것은 콘텐츠지 디자인이 아니다. 이 앱에는 이미 확립된 시각 언어가 있다 — LaTeX/arXiv 논문 조판을 따르는 정형 미니멀리즘. 규칙선, 각진 모서리, 활자 위계, 그리고 단 하나의 강조색.

공개 페이지 22개가 새로 붙는다. 회칙 같은 장문 규범, 세미나·스터디 같은 색인, 갤러리 같은 도판. 셋 다 이미 이 언어 안에 자연스러운 자리가 있다. 논문에는 본문이 있고, 참고문헌 목록이 있고, 도판이 있다. 새 시각 체계를 만들 필요가 없다 — 기존 체계의 아직 안 쓴 부분을 쓰면 된다.

아래는 그 확장안이다. 각 화면을 도판으로 제시하고, 캡션에 설계 근거를 단다.

§1장문 규범

회칙은 5장 11조에 개정본 2건이 딸린 최대 작업 항목이다. 조문 번호는 장식이 아니라 인용 단위이므로, 번호가 본문 왼쪽에서 읽히고 개정 이력이 문서에 붙어 있어야 한다.

§2색인

세미나 25건, 스터디 17건. 카드 그리드가 아니라 참고문헌 목록으로 짠다. 학기가 1차 정렬 축이고, 자료 유무가 한눈에 보여야 한다.

§3도판

사진 48장이 세 갈래(세미나·스터디·회식)로 나뉜다. 논문의 도판 판(plate)처럼 번호와 캡션을 붙이고, 격자는 얇은 선으로만 구분한다.

§4명부

역대 회장단은 4기수. 개인 이메일 7건이 현재 공개돼 있으나 대표 주소로 치환한다 — 회원 명단 공개(D2)와 개인 연락처 공개는 별개 판단이다.

§5토큰

새 팔레트를 만들지 않았다. 아래는 src/lib/manuscript.css의 :root에 이미 있는 값 그대로다.

§6가져오지 않는 것

이 항목이 이 문서의 존재 이유다. 콘텐츠는 전부 옮기되, Notion이 그것을 보여주던 방식은 하나도 따라가지 않는다.

Notion에 두고 간다

  • 이모지 페이지 아이콘 (📢 🧭)
  • 토글 접기 — 콘텐츠를 숨겨 크롤러도 사람도 놓친다
  • 둥근 카드·회색 배경 블록
  • 32자 UUID URL
  • 사이드바 트리 내비게이션
  • 인라인 DB 뷰 전환 탭
  • 기본 산세리프 본문

대신 쓰는 것

  • 절 번호(§)와 규칙선
  • 펼친 본문 + 방주 — 이력은 숨기지 않는다
  • 1px 경계, border-radius: 0
  • /about/charter 같은 읽히는 경로
  • 상단 3구획 내비 (About · Archive · Seminar)
  • 페이지당 하나의 정해진 표현
  • Newsreader / Crimson Pro / Gowun Batang
  • 01
    공개/비공개 경계가 시각적으로 보여야 한다

    지금 이 앱은 / 말고 전부 로그인 뒤다. 공개 영역이 새로 생기므로, 상단 우측 Sign in이 유일한 경계 표지다. 로그인 후에는 같은 자리가 유틸리티 레일(ADMIN · DB · 로그아웃)로 바뀐다.

  • 02
    정적 페이지는 조회하지 않는다

    회칙·회장단·홍보문은 레포에 박아 빌드 타임에 낸다(D1). 화면에는 안 보이지만 이 결정이 §1·§4의 렌더링 방식을 정한다 — 스켈레톤도 로딩 상태도 필요 없다.

  • 03
    도판은 파생본으로 낸다

    사진 48장을 원본 해상도로 CloudFront에서 내면 갤러리 한 페이지가 수십 MB가 된다. 썸네일 생성이 §3의 전제다.
