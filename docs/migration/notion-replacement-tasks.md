### 1-1. 정합성 이상 (실측)

```
private-info 240 = 229 (회원 연결) + 11 (미연결)
members      231 = 229 (개인정보 有) + 2 (개인정보 無)
applications   9 = 전부 accepted=true, 그러나 8건만 회원으로 연결됨
```

| 분류 | 건수 | 조치 |
|---|---|---|
| 이메일조차 없는 private-info | 5 | 삭제 후보 — 동아리 확인 후 |
| 🔴 이메일 있고 회원·신청 어디에도 대응 없는 private-info | 5 | **주인 없는 개인정보.** 보유 근거 확인 → 삭제 또는 소유자 연결 |
| 신청과 대응하나 회원 미연결 | 1 | 승인 1건이 중간 실패한 흔적. 회원 생성 완료 또는 신청 취소 |
| 개인정보 없는 회원 | 2 | 연락 수단 없는 회원. 확인 필요 |

발생 시기가 2026-03~04에 몰려 있고 이후 신청 건은 정상이다. **진행형 문제는 아니지만
옮기고 나면 찾기 더 어려워진다.**
