# 동아리 업무 중심 프런트엔드 전환 검토

## 범위와 기준

현재 main `6d82016707a75a57816bc77c0b9c66e33eef6d6e`를 기준으로 누적 전환 패치를 적용했습니다. 기존 UI 작업 디렉터리를 수정하거나 덮어쓰지 않았습니다. 복원한 소스 676개 파일의 SHA256이 전달된 소스 manifest와 모두 일치하며, 저장소에 없는 운영 스크립트를 삭제하지 않았습니다.

공개 홈의 `GuestLanding.svelte`는 main과 바이트가 같습니다. 원래 스크롤·메뉴의 공개 홈 정체성을 유지하며, 회원 업무 화면에는 낮은 밝기의 종이 배경과 논문형 요소를 사용합니다.

## 기능별 변경

- 회원 홈·메뉴: 해야 할 일, 내 스터디, 세미나 진행, 활동·출석 기록을 구분하고 역할·상태에 맞는 이동을 제공합니다.
- 스터디·세미나: 탐색, 상세, 개설·발표 제안, 신청·대기·철회, 승인·일정·공개 상태를 연결합니다.
- 가입·계정: 가입 원고와 명시적 동의를 실패 후 복원하고, 대기·수정·공지·연락처 공개·탈퇴의 상태와 확인 절차를 분리합니다.
- 출석: 참가자·발표자·운영자 흐름의 처리 중 상태, 재시도, 실패 안내를 구분합니다.
- 관리자: 회원 검토, 세미나·스터디 기록 편집, 임원진 학기·직위 선택, 메일 템플릿·변수·규칙 편집을 개선합니다. 관련 없는 작업 결과가 다른 초안을 지우지 않도록 합니다.
- 공개 기록: 세미나 목록·상세와 회장단의 실제 현재 학기 표시를 정리합니다. 없는 원자료를 새 자료인 것처럼 만들지 않습니다.

변경 세부 사항은 `docs/FEATURES.md`, `docs/COMPONENTS.md`, `docs/spec/API-SPEC.md`에 함께 반영되어 있습니다.

## 이번 게시 전 재검증

2026-10-04 UTC, Node 24.19.0 / pnpm 11.19.0에서 lockfile 고정 설치 후 실행했습니다. 저장소 CI는 Node 22와 packageManager에 지정된 pnpm을 사용하므로 원격 CI 결과를 별도로 확인해야 합니다.

- Prettier 전체 검사: 통과
- ESLint 전체 검사: 통과
- Vitest 전체: 165개 파일 통과, 1개 파일 생략; 1,791개 테스트 통과, 2개 생략
- Svelte/TypeScript: 오류 0, 경고 0
- production build: 통과
- 누적 patch의 clean-main 적용 검사, 676개 소스 해시 검사, `git diff --check`: 통과
- 공개 홈 SHA256: `e0c9b5a992cf65a542015e2add1a0eb181253faada3cf55cb414bd66445e8987`

기존 인계 증거에는 최근 임원진·메일 작업의 격리 HTTP 29개, 실제 Svelte/Kit enhance 기반 jsdom 14개, 전후 SSR 24개 상태가 있습니다. 이 수치는 이번에 다시 실행한 전체 품질 게이트와 구분합니다. 격리 검증은 가상 회원과 메모리 자료를 사용했고 실제 메일을 발송하지 않았습니다.

## 검토 순서

1. 공개 홈 보존과 회원 홈·내비게이션 경계를 확인합니다.
2. 신청·실패 후 원고 복원·중복 제출·취소·철회를 확인합니다.
3. 운영자 검토·출석·기록 편집의 권한과 서비스 호출 계약을 확인합니다.
4. 임원진 학기 문맥과 메일 편집기의 독립적인 초안·결과 처리를 확인합니다.
5. 아래 실제 연동·브라우저 수용 검사를 마친 후 병합 여부를 결정합니다.

## 아직 필요한 수용 검사

- 실제 브라우저의 모바일 레이아웃, 키보드·화면 읽기, hydration, 뒤로·앞으로 이동
- 운영 OAuth 로그인, 실제 계정별 권한, Supabase RLS·Storage, 메일 발송·수신
- 원래 누락된 문제·토론 PDF 등 실제 자료 확보

이번 클라우드 브라우저의 로컬 검토 HTML 열기는 `net::ERR_BLOCKED_BY_CLIENT`로 차단되어 실제 스크린샷을 새로 검증하지 못했습니다. 기존 이미지 자료는 코드 레이아웃 표현이며 브라우저 스크린샷으로 간주하지 않습니다.

이 변경은 검토용 draft PR입니다. 운영 계정·데이터·권한을 바꾸지 않았으며 병합이나 운영 배포를 수행하지 않습니다.
