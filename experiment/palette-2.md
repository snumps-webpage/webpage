# Palette 2 — Modern Theorem (Modern/Tech-forward)

## Concept

A digital-first palette that emphasizes the "computational" side of mathematics. It uses high-vibrancy electric blues and deep space blacks to create a sleek, high-tech interface that feels advanced and precise.

## Color System

| Token                  | HEX     | Usage                                    |
| :--------------------- | :------ | :--------------------------------------- |
| --color-primary        | #3182CE | Tech-blue for primary actions            |
| --color-secondary      | #2D3748 | Deep slate for UI structure              |
| --color-accent         | #00B5D8 | Vibrant cyan for progress and highlights |
| --color-bg             | #0F172A | Deep space background                    |
| --color-surface        | #1E293B | Card surfaces and elevation              |
| --color-text-primary   | #F8FAFC | Clean white for high readability         |
| --color-text-secondary | #94A3B8 | Muted gray for secondary data            |
| --color-text-muted     | #64748B | Disabled or meta-info                    |
| --color-border         | #334155 | High-definition borders                  |
| --color-success        | #48BB78 | Neon green for status                    |
| --color-warning        | #ECC94B | Bright gold for alerts                   |
| --color-error          | #F56565 | Vivid red for errors                     |

## Accessibility Notes

- Neon accents are tuned to ensure 4.5:1 contrast against surface.
- Focus ring uses a double-ring strategy (white then primary) for maximum visibility on dark backgrounds.
