# Palette 1 — Academic Legacy (Conservative/Institutional)

## Concept
This palette is inspired by traditional academic institutions and the feel of historical libraries. It uses deep "Oxford Blue" and "Academic Crimson" against a warm, off-white background to evoke authority, history, and stability.

## Color System
| Token | HEX | Usage |
| :--- | :--- | :--- |
| --color-primary | #1A365D | Primary actions, branding, key headers |
| --color-secondary | #3E2723 | Secondary accents, subtle brand details |
| --color-accent | #9B2C2C | Call to action, critical highlights |
| --color-bg | #FDFBF7 | Main page background (Paper feel) |
| --color-surface | #F4F1EA | Cards, sidebars, secondary regions |
| --color-text-primary | #1A202C | Main body text, titles |
| --color-text-secondary | #4A5568 | Subtitles, descriptive text |
| --color-text-muted | #718096 | Meta info, placeholder text |
| --color-border | #D1D5DB | Subtle structural lines |
| --color-success | #2F855A | Successful states, approved status |
| --color-warning | #C05621 | Pending states, alerts |
| --color-error | #9B2C2C | Destructive actions, errors |

## Accessibility Notes
- Contrast ratio for Primary on Background: 12.5:1 (Pass AAA)
- Text Primary on Surface: 11.2:1 (Pass AAA)
- Accent derivation for hover: 10% darkening applied to primary.
