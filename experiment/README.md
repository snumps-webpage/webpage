# Color Identity Experimentation System

This directory contains a series of color palette experiments for the SNUMPS Automation platform. Each experiment tests a different strategic visual direction while maintaining the core functionality and prestigious academic tone of the brand.

## Visual Identity Diagnosis

### 1. Brand Positioning
SNUMPS (Seoul National University Mathematical Problem solving Society) is an elite academic club. The platform serves as an automation tool for its internal operations.
- **Tone**: Academic, Institutional, Technical, Prestigious.
- **Typography**: Editorial Serif mix (`Crimson Pro`, `Newsreader`, `Gowun Batang`) with high-contrast Monospaced accents (`JetBrains Mono`).
- **Layout Density**: Dashboard-like, information-heavy but structured.
- **Visual Hierarchy**: Strong emphasis on readability and data clarity.

### 2. Intended Perception
- **Emotional Tone**: Intellectual, Focused, Trustworthy, "Physical Paper" feel.
- **User Perception**: A digital extension of a prestigious mathematical journal or a private library.
- **Interaction Style**: Calm, focused, premium, and neutral.

## Selection Recommendation

### Primary Direction: Palette 1 — Academic Legacy
**Rationale**: This palette most accurately reflects the SNU academic heritage while maintaining a high degree of digital polish. The use of "Academic Crimson" and "Oxford Blue" provides immediate institutional authority, and the warm paper background reduces eye strain compared to pure white. It excels in both visual coherence and emotional resonance with the "Math Journal" concept.

### Fallback Option: Palette 3 — Minimal Proof
**Rationale**: For a purely utility-focused interface where branding is secondary to task completion, Palette 3 provides the cleanest, most focused environment. It is timeless and guarantees the highest possible accessibility ratings.
