# Palette 3 — Minimal Proof (Minimal/Monochromatic)

## Concept
Stripping away all non-essential color to focus purely on content and structure. This monochromatic palette uses variations of ink-black and stark white, creating a "chalkboard" or "typeset paper" aesthetic that is timeless and professional.

## Color System
| Token | HEX | Usage |
| :--- | :--- | :--- |
| --color-primary | #000000 | Solid black for primary identity |
| --color-secondary | #4A5568 | Neutral slate for auxiliary elements |
| --color-accent | #2D3748 | Bold structural accents |
| --color-bg | #FFFFFF | Pure white background |
| --color-surface | #F7FAFC | Ultra-light gray for surfaces |
| --color-text-primary | #1A202C | Deep charcoal for reading |
| --color-text-secondary | #4A5568 | Gray for hierarchy |
| --color-text-muted | #A0AEC0 | Low-emphasis metadata |
| --color-border | #E2E8F0 | Hairline borders |
| --color-success | #2D3748 | Structural success indicators (Non-color based) |
| --color-warning | #718096 | Structural warning indicators |
| --color-error | #000000 | Inverted error states |

## Accessibility Notes
- Naturally high contrast due to monochromatic extremes.
- Interactive states rely on weighting (bold/inverted) rather than hue shifts.
