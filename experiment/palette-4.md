# Palette 4 — Scientific Journal (Soft/Human-centered)

## Concept

Designed for long-form reading and intense focus sessions. This palette uses "Nordic" inspired muted greens and warm grays to reduce eye strain. It feels like an organic, scientific notebook, emphasizing comfort and approachability.

## Color System

| Token                  | HEX     | Usage                             |
| :--------------------- | :------ | :-------------------------------- |
| --color-primary        | #2D3748 | Deep charcoal for primary focus   |
| --color-secondary      | #4A5568 | Soft slate for structure          |
| --color-accent         | #38A169 | Leaf green for growth and success |
| --color-bg             | #EDF2F7 | Cool, soft gray background        |
| --color-surface        | #E2E8F0 | Subdued surfaces                  |
| --color-text-primary   | #2D3748 | Easy-on-the-eyes text             |
| --color-text-secondary | #4A5568 | Accessible gray secondary text    |
| --color-text-muted     | #718096 | Meta info                         |
| --color-border         | #CBD5E0 | Organic borders                   |
| --color-success        | #38A169 | Natural green for approval        |
| --color-warning        | #D69E2E | Warm amber for alerts             |
| --color-error          | #E53E3E | Soft red for destructive actions  |

## Accessibility Notes

- Muted tones are carefully balanced to maintain WCAG AA compliance.
- Surface transitions use gentle shadows to maintain depth without high-frequency edges.
